# Promo codes and QR activation

Some tools, or some ways of starting a tool, are not in the catalogue. An organisation or a tool's
author can give you a **code** — typed, or carried by a QR code — that opens them.

## Using a code

1. Open the menu and tap **Premium**.
2. Tap **Have a promo code?**, then type the code and tap **Apply** — or tap **Scan a QR code**
   and point the camera at it. Where there is no camera, paste the text the QR code holds.

What happens next depends on the code:

- **Add a tool** — the tool appears on Home and stays there.
- **Open a tool once** — the tool opens for this visit only and is not added anywhere.
- **Open a tool in a particular way** — for example, the calculator in its scientific mode.

Most codes ignore case, spaces and dashes. A code written in brackets must be typed exactly as
given, brackets included.

## Links

A link of the form `unitool://app/<tool>` opens a tool directly. Phones open such links from a QR
code scanned with the system camera, or from a message. A link can pre-fill a form — adding a 2FA
account, for instance — but it never saves anything on its own: saving is always your tap.

## What a code cannot do

A notification can never open a hidden tool; only a code can. The app keeps codes only as one-way
hashes, so the list of valid codes cannot be read out of it. A code can also expire, and then the
app says so.
