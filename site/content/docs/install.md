# Install

## Android

Unitool is in testing on Google Play. While it is, the store page opens only for testers; once it
is public, this page will link to it.

The app needs Android 7.0 or later. It asks for no permission when it first opens. The
[privacy policy](/privacy/#permissions) lists every permission it has and when each one is used.

## iPhone and iPad

Unitool is in testing on TestFlight, Apple's beta programme. Install **TestFlight** from the App
Store, then open the invitation link you were given.

On an iPhone, 2FA keys are sealed by the Secure Enclave, the chip Apple keeps keys in.

## Desktop and web

There are no packaged desktop or web releases. Both run from the source with one command; see
[Build from source](/docs/build-from-source/).

## Command line

`unitool` is a native Linux program built from the same repository. See
[The unitool command](/docs/cli/#install).

## Updating and removing

The stores update Unitool like any other app. Removing it deletes everything it stored, including
the key that protects your 2FA accounts — so [export them](/docs/two-factor/#moving-to-a-new-phone)
first if you want to keep them.
