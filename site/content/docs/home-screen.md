# Home screen and apps

## Home

Home shows the tools you chose, not every tool there is. A fresh install starts with the calculator
and a **+** tile.

- **Tap a tile** to open the tool.
- **Tap +** to open **All apps**, the catalogue. Tap a tool there to put it on Home, or tap it
  again to take it off.
- **Long-press a tile** to take it off Home. The tool and its data stay; it is back in the
  catalogue, one tap away.

## The menu

The ☰ button at the top left opens the menu: Home, All apps, Settings and Premium, where promo
codes are entered (see [Promo codes and QR activation](/docs/activation/)). The entry for the screen you are on is greyed out rather than
hidden, so the menu never changes shape.

The bottom of the menu shows the version and build number — useful when reporting a problem.

## Settings

| Setting | What it does |
|---|---|
| **Language** | English or Russian. Switches at once, no restart. |
| **Haptics** | The short tap you feel under each key. |
| **Protection** | Which tools open only with your fingerprint, face or screen lock, and how soon they lock again after you leave. See [the app lock](/docs/security/#the-app-lock). |
| **Notifications** | Shown once you use a tool that sends them; can ask for the permission again if you refused it. |
| **Currency converter** | Which currency it starts from. |

## Back

The system Back gesture closes the menu if it is open, then steps back inside the tool, then
returns to Home.
