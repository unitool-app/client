# Calculator

The calculator is on Home from the first start. The answer is the largest thing on the screen.

## Keys

| Key | Does |
|---|---|
| `0`–`9`, `.` | enter a number (the decimal key follows the interface language: `.` in English, `,` in Russian) |
| `+` `−` `×` `÷` | the four operations |
| `%` | percent, read the way a pocket calculator reads it |
| `±` | flip the sign of the number you are typing |
| `⌫` | delete the last character |
| `C` | clear everything |
| `=` | the result |

## How it counts

- **Left to right.** `2 + 3 × 4` gives 20: each operation applies to the result so far, as on a
  pocket calculator. Keep pressing operations and the sum keeps going without re-entering anything.
- **Percent of the running total.** `200 + 10 %` adds ten percent of 200 and gives 220.
  `200 × 10 %` gives 20, and `50 %` on its own gives 0.5.
- **Decimal results read as decimals.** `0.1 + 0.2` shows `0.3`, not the binary
  `0.30000000000000004`.
- **Errors say so.** Dividing by zero shows *Error*, and every key but `C` waits until you clear it
  — carrying on from a number you never saw would be worse.

## Scientific mode

A row of extra keys — `x²`, `√` and `1/x` — appears in scientific mode. It is switched on by an
[activation code or link](/docs/activation/) rather than a setting, so a school or a team can hand
out a calculator already set up the way they want it.

## Haptics

Each key gives a short tap. Turn it off in **Settings → Haptics**.
