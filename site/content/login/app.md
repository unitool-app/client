# This is a sign-in code for the Unitool app

The code you scanned signs a browser in to this website. It works only from inside the app:

1. Open **Unitool**.
2. Go to **Settings → Website** and tap **Scan QR code to sign in**.
3. Point the camera at the code on the computer again.

The phone shows which browser asked, and nothing happens until you tap **Sign in** there.
If you did not ask to sign in anywhere, ignore the code.
