# .ai-notes/public-keys — чужие открытые ключи на телефоне; передача через QR

> **Версия:** 1.0 · **Статус:** построено, verify.sh PASS, отправлено в main · **Дата:** 2026-10-11
>
> Решения продолжают сквозную нумерацию (`messenger`: последние D505 и вопрос 227). Здесь решения
> D506–D515; вопросов нет — владелец принял предложенное целиком («да все нормально делаем»).

## Что сказал владелец (близко к тексту)

> «Надо сделать, чтобы можно было публичные ключи тоже добавлять локально, не только [с GitHub].
> И надо сделать, чтобы можно было показать публичный ключ на одном телефоне, а на другом прочитать
> и добавить только публичный, чтобы им шифровать, а другой телефон мог потом расшифровать.»

## Как это выглядит

- **Телефон Б** (владелец ключа): «SSH-ключи» → ключ → «Показать QR». На экране QR со строкой
  `authorized_keys` (`ssh-ed25519 AAAA… comment`) и отпечаток. Приватная половина не двигается.
- **Телефон А**: «SSH-ключи» → «Добавить открытый ключ» (или то же из «Резервной копии») →
  сканировать QR / вставить строку / открыть `.pub`. Экран подтверждения: тип, полный отпечаток
  («сверьте с экраном того телефона»), имя. «Сохранить».
- Дальше на А: бэкап и экспорт 2FA предлагают сохранённые ключи рядом с GitHub.
- На Б: «Восстановить» в бэкапе и импорт экспорта 2FA уже открывают файл своим ключом — нового
  кода там нет.

## Решения

- **D506.** Чужой открытый ключ — отдельный вид записи, «получатель»: только открытая половина,
  имя, дата. Им можно только шифровать. Не `SshKeyInfo` и не в `SshKeyAdmin` — контракт Superizer
  не меняется; всё в Unitool (`services/ssh`), как и решено в ssh-new D181.
- **D507.** Хранится в файле keyring (`RecordsFile.known`), рядом со своими ключами. Файл стирается
  целиком только когда нет ни своих ключей, ни грантов, ни получателей. В бэкап не попадает (как и
  весь файл keyring, I10); после переезда на новый телефон получателей добавляют заново.
- **D508.** Принимаются только ключи, на которые умеет шифровать age: Ed25519 и RSA от 2048 бит
  (`Age.supports`). ECDSA, в том числе ключ из Secure Enclave iPhone, отклоняется со словами почему
  (crypt Q159 о P-256 получателях остаётся открытым).
- **D509.** Свой ключ получателем не добавляется («это ваш ключ»); тот же отпечаток второй раз —
  тоже («уже сохранён как …»).
- **D510.** QR содержит ровно строку `authorized_keys` с комментарием — ту же, что «Копировать».
  Любой сканер её прочитает, а `qrencode < id_ed25519.pub` на компьютере даёт QR, который телефон
  примет.
- **D511.** Подлинность: QR, отсканированный с экрана рядом, достаточен. На экране подтверждения и на
  экране QR показывается полный отпечаток `SHA256:…`, чтобы его можно было сверить, если ключ пришёл
  вставкой или файлом.
- **D512.** Приложениям — только чтение: сервис `PublicKeyBook` (`ServiceKey("public-keys")`) со
  списком. Добавлять, переименовывать и удалять может только хост (`PublicKeyBookAdmin`): приложение,
  которое подсовывает получателя, могло бы увести зашифрованное.
- **D513.** Управление — в «SSH-ключах» (вход по промокоду, как сейчас): вторая карточка «Открытые
  ключи других устройств». «Добавить открытый ключ» есть и в «Резервной копии», потому что та
  доступна всем.
- **D514.** Бэкап: получатели = отмеченные сохранённые ключи + ключи найденного GitHub-логина. Хватает
  любого одного источника. Сохранённые по умолчанию не отмечены.
- **D515.** Экспорт 2FA: так же — отмеченные сохранённые ключи + GitHub. Команды для компьютера
  (`age -d -i ~/.ssh/…`) показываются по тем же правилам; без GitHub-логина сообщение при отправке
  не называет логин.

## Код

- `services/ssh`: `PublicKeyBook`, `PublicKeyBookAdmin`, `KnownKey`, `AddKnownOutcome`; запись
  `KnownRecord` в `RecordsFile`; `SshKeyringHost.publicKeys`.
- `composeApp`: `KnownKeysCard` в `SshKeysScreen`, `AddPublicKeyScreen`, `KnownKeyCardScreen`,
  `PublicKeyQrScreen` (кнопка «Показать QR» в карточке своего ключа), источник «Сохранённые ключи»
  в `BackupScreen`; строки En/Ru.
- `apps/twofa`: сохранённые ключи в странице экспорта.
- Тесты: keyring (добавить/отказы/переименовать/удалить/файл не стирается), экраны (QR своего ключа,
  добавление вставкой, бэкап на сохранённый ключ), 2FA (экспорт на сохранённый ключ, открывается
  своим ключом).
