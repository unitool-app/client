## 4. Отступления от заметок (все с «(impl)» на месте)

| Где | Что и почему |
|---|---|
| 07 §6 | Контракт 3 в точности, как вошёл в 0.4.0 |
| 06 после §6.1 | Каталог в библиотеке — `DiagnosticsCode` (код, статус, действия); тексты только в хосте |
| 01 §5.7 | На Android 15 система при снятии PIN удаляет ключи с привязкой к аутентификации, а не делает их `KeyPermanentlyInvalidated` (P7) |
| 02 §2 | Ключи, добавленные через `ssh-add`, живут только в памяти агента: пароля в протоколе нет (D167) |
| 03 §2, 04 шаг 4 | Правила бэкапа Android — только `include`; `exclude` запрещает release-lint. Охраняет `BackupRulesTest` |
| 04 §9 Б4 | Сейф хоста — тот же ключ Keystore/Keychain, что был у 2FA, поэтому старые аккаунты открываются |
| 01 §5.1 | `KeyAgreement` не кладётся в `CryptoObject` ни на одном API: X25519-близнец резидентного Ed25519 открыт 5 с после системного промпта; скаляр из чипа не выходит |
| 04 шаг 5 | Без `androidx.biometric` и отдельной активности; один `KeystoreBackend`; ниже API 30 — только уровень 3; два набора констант аутентификации |
| 04 шаг 5b, §2 | iOS-хост на уровне 3 до зелёного отчёта с iPhone; P10–P13 отвечает `SecureEnclaveSelfTest` |
| 04 §9 Б11 | CI-job `device` (эмулятор API 33) зелёный 2026-09-26: vault 10, ssh 7, composeApp 3. Сначала освобождает диск (иначе эмулятор не стартует); тест выключения экрана сперва будит экран; тест защищённого окна снимает keyguard, а отказ `screencap` на API 33 (снимка нет вовсе, на API 35 — чёрный) считает «ничего не видно» при условии, что Настройки снимаются |
| 01 §4.1 | Curve25519 в Keystore определяется пробным импортом, а не `API ≥ 33`: эмулятор API 33 отвечает «Unsupported key algorithm: XDH». Там Ed25519 запечатывается ключом чипа (уровень 2). В alpha 1011 ещё старая проверка |
| 02 §5 (шаг 6) | Источники мастера — `HostTools` (те же сервисы, что у приложений); экраны на узком `KeysUi`; мастер держит копию файла и сам решает про «Задать пароль» до `import`; нет QR открытого ключа (нет кодировщика) и переименования; уровень словами — `KeyFindings` |
| 06 §7 (шаг 6) | Баннер — худшая находка словами каталога, не отдельная фраза; в 2FA нет кнопки «Добавить ключ» (приложение не открывает экраны хоста); «Make a backup» без кнопки до шага 7; отчёт не обновляется от записи секрета приложением |
| 07 §4 | `services/file-picker` сделан в шаге 6, а не 7: без него мастеру нечем открыть файл |
| 02 §6.8 (шаг 7) | `GitHubKeys` скопирован из 2FA в `services/backup`; `openForHost` с исходом; `HostTools.network` и `ktor-client-core` в `composeApp`; «поделиться» на desktop — сохранение, в браузере — скачивание; нет кнопок подписи в тестовом приложении (библиотека заморожена) |

Стоп-линии 00 §5 пока не задеты. Ближайшая — шаг 7: текст `play/PRIVACY.md` и листинга
будет предложен в заметке, а не вписан.
