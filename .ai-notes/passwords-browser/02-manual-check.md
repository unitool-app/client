# 02 — ручная проверка на двух телефонах (для владельца)

> 2026-10-25, шаг 7. Автоматически проверено всё, что можно без телефона (PROGRESS.md). На
> настоящих Android и iPhone **ничего не запускалось** — ни слушатель, ни mDNS, ни разрешения.
> Этот список — то, что нужно пройти руками. Отметки — в таблице в конце.

## Подготовка

**Компьютер (Linux):**
1. `./gradlew :unitool-cli:app:install`, затем `unitool-cli/bin/unitool browser install`. Он пишет
   манифесты для найденных браузеров и обёртку `~/.local/share/unitool/browser-host`.
2. `cd unitool-browser && npm ci && npm run build`.
3. Chrome/Chromium: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» →
   `unitool-browser/dist/chrome`. id должен быть `omcnlonedghinfecceojlapofcjfcpoi`.
4. Firefox: `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» →
   `unitool-browser/dist/firefox/manifest.json`.
5. SSH-ключ `~/.ssh/id_ed25519` без парольной фразы. Для отдельной проверки нужен ещё ключ под
   фразой.

**Телефоны:** сборка с этой ветки. Android — `./gradlew :composeApp:installDebug`. iPhone —
TestFlight; он собирается только пушем в `main` (это выпускает alpha) или меткой `testflight` на PR —
решать вам. В «Паролях» нужна запись для сайта проверки, например `https://github.com` с логином.

## Сценарии (на каждом телефоне)

| # | Что сделать | Чего ждать |
|---|---|---|
| 1 | На странице входа (github.com/login) нажать значок Unitool или Ctrl+Shift+L | Попап: «Привяжите телефон…» и кнопка «Привязать телефон» |
| 2 | «Привязать телефон» | QR, имя компьютера, отпечаток `SHA256:…` ключа SSH, таймер 5 мин |
| 3 | На телефоне: Unitool → Пароли → «Компьютеры» → «Привязать компьютер», скан | «Привязать «<имя>»?» и тот же отпечаток, что в попапе. **iPhone:** запрос «Локальная сеть» появляется после «Привязать» (D551), а не при установке |
| 4 | «Привязать» | Телефон: «Ждём компьютер…», затем «Привязано: <имя>». Попап: «Привязано: Unitool · Android» / «Unitool · iPhone» |
| 5 | Закрыть «Пароли» на телефоне. На компьютере Ctrl+Shift+L | Попап: «Ищу телефон… Откройте «Пароли» на телефоне», отсчёт |
| 6 | Открыть «Пароли» (разблокировать) | Попап: «Телефон найден» → «Подтвердите на телефоне». На телефоне лист: сайт крупно, «<компьютер> · Chrome NNN · Linux (по словам компьютера)», запись выбрана |
| 7 | «Отправить» | Биометрия, каждый раз. Затем попап: «Вставлено: <логин>», поля заполнены, форма **не** отправлена |
| 8 | Ещё раз, «Отказать» | Попап: «Отказано на телефоне», поля пустые |
| 9 | Ещё раз, ничего не нажимать 60 с | Лист исчезает; попап: «Телефон не ответил» |
| 10 | Пока попап ищет телефон — свернуть Unitool на телефоне | Телефон не находится, пока Unitool не на экране (D538). Вернуть — находится |
| 11 | Оставить «Пароли» открытыми без касаний больше минуты | Хост закрывает приложение (idle 1 мин); компьютер телефон больше не находит |
| 12 | Сайт без записи (любой другой) → Ctrl+Shift+L | Лист: «Для этого сайта записей нет», поиск; выбрать запись github → **красное** «Сайт записи — github.com, а просит …» |
| 13 | IDN-сайт (например, `https://пример.рф`, если откроется, или любой `xn--`) | На листе сайт в Unicode и строка «В адресе: xn--…» |
| 14 | Страница, где нет поля пароля (первая страница двухшагового входа) | Попап: «На странице не нашлось поля для пароля», кнопки «Копировать логин/пароль», честная строка про буфер обмена |
| 15 | На телефоне «Компьютеры» → компьютер → «Забыть компьютер» (спросит устройство). Затем Ctrl+Shift+L | Попап: «Телефон не узнал этот компьютер. Привяжите его заново.» (или «не нашёлся», если других привязок нет и телефон не слушает) |
| 16 | Журнал на карточке компьютера | Время, сайт, итог. **Логинов нет** |
| 17 | Телефон в мобильной сети / гостевой Wi-Fi с изоляцией клиентов | «Телефон не нашёлся за минуту…» — кабеля в v1 нет (D548) |
| 18 | **iPhone:** в Настройках выключить Unitool → «Локальная сеть», попробовать | Не находится; попап советует разрешить локальную сеть. Включить — работает |
| 19 | **Android:** поиск с компьютера при выключенном и при включённом экране телефона | Слушает только при включённом экране и открытых «Паролях» |
| 20 | `unitool browser pair` в терминале вместо попапа | QR в терминале; дальше как 3–4 |
| 21 | `unitool browser pair --key ~/.ssh/ключ_под_фразой` | Отказ до QR: «…защищён фразой — такие пока не поддерживаются; укажите другой: --key» |
| 22 | Firefox (из .deb, а на Ubuntu — из snap) | То же, что 5–7. Snap: один раз окно «разрешить Firefox запускать Unitool» (D555) |
| 23 | Два компьютера привязаны; второй просит, пока у первого открыт лист | Второму: «На телефоне уже открыт запрос другого компьютера» |
| 24 | `adb logcat` во время 6–7 | Ни пароля, ни логина в журнале |

## Что ещё посмотреть

- Батарея Android: `MulticastLock` держится только пока «Пароли» на экране (`adb shell dumpsys wifi | grep -i multicast`).
- На Android 14+ `NsdManager` объявляет имя из 16 hex-знаков — не имя телефона.
- Пароль не остаётся в буфере обмена телефона (лист копирования не использует).
