# .ai-notes/passwords — мини-приложение «Пароли»

> **Версия:** 1.0 · **Статус:** построено 2026-10-25, тесты зелёные, не закоммичено · **Дата:** 2026-10-25
>
> Решения D522–D533, вопросы 228–232 закрыты. Следующие номера: D534 / Q233.

## Что сказал владелец (близко к тексту)

> «Сделай программу для хранения паролей. Мини-апп. Чтобы можно было как с 2FA, всё в канонах.»

Ответы на 0.1: генератор нужен (229), импорт нужен (230), Autofill — потом (231), мастер-пароль
не нужен (232), экспорт — по аналогии с 2FA. 228 (поля) без ответа — оставлены предложенные.

## Что построено

- **D522.** `apps/passwords`, AppId `passwords`, пакет `cx.m42.apps.passwords`, `PasswordsApp`,
  «Пароли» / «Passwords», категория Security, иконка — ключ. Публичное, в каталоге (D48).
  Зарегистрировано в `UnitoolHost`, тесты — в `verify.sh`. `minHostContract = 3`.
- **D523. Запись** (`PasswordEntry`): название, логин, пароль, сайт, заметка, дата изменения.
  В списке название; если его нет — хост сайта; если и его нет — логин.
- **D524. Хранение — как у 2FA.** Одним JSON в `runtime.secrets["entries"]` (`EntryStore`). Mutex,
  запись под `NonCancellable`; не запечаталось — не пишется ничего; запертый/нечитаемый список не
  перезаписывается (те же три `StorageProblem`, «Разблокировать»).
- **D525. Защита — как у 2FA.** `LockPolicy.Required`, `secureWindow`, idle-закрытие хоста.
  Подтверждение устройством: «Показать», «Изменить» (в форме пароль виден), «Экспорт», «Удалить».
- **D526. Список.** Поиск (по названию, логину, сайту — не по паролю и заметке), по алфавиту,
  в строке «Копировать». Тап по строке — карточка. Внизу «Импорт» и «Экспорт».
- **D527. Карточка.** Логин (тап — копировать), пароль точками: «Копировать» без подтверждения,
  «Показать» с подтверждением, прячется через 60 с. Сайт, заметка, «Изменено …», «Изменить»,
  «Удалить» (кнопка + устройство).
- **D528. Буфер — как у 2FA.** `SecretClipboard` (копия `CodeClipboard`): sensitive, пароль стирается
  через минуту (логин — нет). На iOS — expiration + localOnly.
- **D529. Генератор.** 20 символов, буквы/цифры/знаки, хотя бы по одному каждого, без похожих
  (l I O 0 1) и без кавычек, запятой, обратной косой. `secureRandomBytes` из unitool-kit, без смещения.
- **D530. Экспорт — как у 2FA.** age v1 на ключи GitHub-логина и/или сохранённые ключи устройств,
  share sheet или буфер. Внутри — **CSV с заголовком Chrome** `name,url,username,password,note`:
  такой файл после `age -d … > passwords.csv` берут Chrome, Bitwarden и другие. Команды на странице:
  расшифровать в терминал и перенести QR-кодом (`| qrencode`, длинное — `split -l`).
- **D531. Импорт** (`Page.ImportFrom` → `Page.Import`):
  - файл: CSV как есть, или `.age` экспорт — через `SshKeyring`, если ключ на телефоне; без
    keyring — «на телефоне нет ключа»; байты файла затираются;
  - камера: QR-коды экспорта, «Сканировать ещё» собирает части в один список (у частей после
    первой нет заголовка — читаются в порядке колонок экспорта);
  - вставка текста CSV.
  Предпросмотр с переключателями, «уже есть» (тот же логин+пароль и тот же сайт/название), строки
  без пароля показаны с причиной. Deep link на добавление нет.
- **D532. Заголовки CSV:** Chrome, Firefox (нет названия → хост), Safari/Apple Passwords, Bitwarden
  (только `type=login`), KeePassXC, 1Password — по именам колонок. Парсер RFC 4180: кавычки,
  переводы строк внутри, BOM, `\r\n`.
- **D533. Снимок сессии:** страница, поиск, логин GitHub, у новой записи — название/логин/сайт.
  Никогда пароль и заметку (туда кладут коды восстановления). Редактирование возвращается карточкой.

## Тесты

`apps/passwords/src/desktopTest`: `CsvTest` (11), `PasswordsInstanceTest` (19),
`PasswordsContractTest` (10) — 40 зелёных. Экспорт проверен расшифровкой независимым `JcaAge`
(копия из 2FA). Хост: 76 зелёных; седьмая строка каталога увела две строки за край в
`ShellTest`/`ExtensibilityTest` — там добавлен `performScrollTo()`. APK и wasm собираются.

## Чего нет / известное

- Autofill (231) — потом. Синхронизации, HIBP, TOTP в записи, мастер-пароля нет.
- `split -l` может разрезать многострочную заметку между QR-кодами — такая запись придёт с ошибкой.
- Номера строк в ошибках импорта считаются заново в каждой отсканированной части.
- На телефоне не проверялось (desktop-тесты, Android/wasm собираются).
