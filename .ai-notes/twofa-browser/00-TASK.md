## 1. Цель одним абзацем

Человек ставит расширение Unitool в браузер и один раз привязывает его к 2FA на телефоне: расширение
показывает QR, 2FA его сканирует. Теперь на странице входа он нажимает значок расширения. Расширение
шифрует запрос («код для github.com, число 47») ключом привязки и отправляет на сервер Unitool. Сервер
шлёт пуш на телефон: «Браузер Chrome · Linux с IP 203.0.113.7 просит код». Человек открывает запрос,
выбирает число 47, аккаунт, подтверждает биометрией. Код, зашифрованный для этого браузера, уходит
через сервер обратно, и расширение вставляет его в поле. Сервер не видит ни сайта, ни кода и не может
выдать себя ни за браузер, ни за телефон. Секрет TOTP телефон не покидает никогда.

## 5. Правила

- **Заметки — спецификация.** Отклонение — сначала правка заметки с пометкой «(impl)» и причиной,
  потом код. Решение, которое требует владельца, — новый вопрос в README (следующий — **204**) и
  стоп по этой части.
- **Протокол меняется только целиком** (01, шапка).
- **Две реализации, не больше.** TypeScript в расширении и `kit.otplink` в Kotlin. 2FA и
  `phone-sim` импортируют `kit.otplink`. Копия — ошибка (05 §4 п. 4).
- **Криптография.** Своё — только склейка 01 §4–§7. Примитивы — `kit.crypto` и `@noble/*`.
  Совпадение доказывает Python `cryptography` (фикстуры) и живой e2e, а не наш же код.
- **Секрет TOTP** читает только `Totp.code`. Ни один путь привязки и запроса не трогает
  `TotpAccount.secret` иначе.
- **Секреты.** Нигде в журналах, исключениях, `toString`, `console`, админке нет кода, `k_req`,
  `k_ans`, `s`, `pt_`, `cs_`, `pas_`, `sealed`. Тесты-канарейки — 02 §7, 03 §8, 04 §3.9.
- **Права расширения** — ровно D448. Новое право — вопрос владельцу.
- **Слова.** 2FA — `TwoFaStrings` (ru + en); расширение — `_locales` (ru + en); тексты пушей —
  `lib/otpTexts.ts` сервера.
- **Стиль.** Kotlin — как в соседних модулях: `explicitApi()` в kit, KDoc «почему». TypeScript
  сервера — как в `app-unitool`. TypeScript расширения — `strict`, без фреймворков.
- **Коммиты** — английские, одна мысль, заголовок о том, что изменилось и почему. Не пушить.
