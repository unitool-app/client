## Явно не в MVP

- Remote config как источник конфига — D2 допускает, не проектируется.
- Общий `PermissionService` — разрешение есть только у пушей (13); камера принесёт свой ключ (D19).
- Стек приложений и обмен результатами — 11.
- Адаптивная раскладка (планшет, две колонки) — D36 фиксирует только максимум ширины.
- Тёмная тема — D37 готовит токены, набор не рисуется.

## Что осталось открытым

Только вопросы 09, требующие ответа владельца (Firebase-проект, домен, источник курсов с RUB,
стек приложений). Ни один не блокирует шаги 1–7 плана: везде действует дефолт.

## Проверка, что ревизия «взялась»

- `AppContractTest`: корневой узел `Content()` найден по тегу `<id>:root`; `FakeClock.advance(25h)`
  → `restoreLastSession()` возвращает null.
- Тест handler-а: `scope.launch { error() }` в экземпляре → `Failed`, событие `Crashed`, следующий
  `launch(id)` успешен.
- Сквозной тест: `HostInfo.debug = false` → семь тапов не открывают Service Menu, промокод открывает.
- Конвертер с `online = false` показывает «офлайн» без единого вызова `FakeNetwork`.
- `verify.sh` в отчёте содержит строки `wasm: <N> KB (budget <M>)` и `apk: …`.
