## Название (30 максимум)

```
Unitool Калькулятор
```

## Краткое описание (80 максимум)

```
Калькулятор без лишнего. Без рекламы, без аккаунтов, без передачи данных.
```

## Полное описание (4000 максимум)

```
Unitool — это калькулятор, и только калькулятор.

Он открывается сразу на клавиатуре. Нет заставки, которую нужно пересидеть, нет аккаунта,
который нужно создать, нет баннера внизу экрана и нет запроса разрешений при первом запуске.
Результат — самое крупное на экране, потому что именно за ним вы и пришли.

ЧТО ОН УМЕЕТ

• Сложение, вычитание, умножение, деление
• Процент — так, как его понимает карманный калькулятор: 200 + 10% прибавляет десять процентов
  от 200
• Смена знака, забой, сброс
• Цепочка вычислений слева направо: 2 + 3 × 4 продолжается без повторного ввода
• Округление результата, поэтому 0,1 + 0,2 показывает 0,3, а не двоичную правду о нём

НАСТРОЙКИ, И ИХ ТРИ

• Язык — русский или английский, переключается сразу, без перезапуска
• Вибрация — короткий отклик под клавишей, включить или выключить
• Номер сборки — на случай, если о чём-то нужно сообщить

КОНФИДЕНЦИАЛЬНОСТЬ

У Unitool нет разрешения на доступ к сети. Он физически не может ничего никуда отправить и не
пытается. Нет аналитики, нет сбора сбоев, нет рекламного идентификатора, нет аккаунта.
Единственное, что он записывает, — две настройки выше, в собственном закрытом хранилище
приложения на вашем устройстве.

Единственное разрешение, которое он запрашивает, — VIBRATE, для отклика под клавишами, и его
можно отключить.

БЕЗ РЕКЛАМЫ. БЕЗ ПОКУПОК. БЕЗ ПОДПИСКИ. БЕЗ ВХОДА.
```
