## Название (30 максимум)

```
Unitool Калькулятор и валюты
```

## Краткое описание (80 максимум)

```
Калькулятор и конвертер валют. Без рекламы, аккаунтов, слежки и входа.
```

## Полное описание (4000 максимум)

```
Unitool — это калькулятор и конвертер валют, и открывается он сразу на клавиатуре.

Нет заставки, которую нужно пересидеть, нет аккаунта, который нужно создать, и нет баннера внизу
экрана. Результат — самое крупное на экране, потому что именно за ним вы и пришли.

КАЛЬКУЛЯТОР

• Сложение, вычитание, умножение, деление
• Процент — так, как его понимает карманный калькулятор: 200 + 10% прибавляет десять процентов
  от 200
• Смена знака, забой, сброс
• Цепочка вычислений слева направо: 2 + 3 × 4 продолжается без повторного ввода
• Округление результата, поэтому 0,1 + 0,2 показывает 0,3, а не двоичную правду о нём

КОНВЕРТЕР ВАЛЮТ

• Справочные курсы Европейского центрального банка
• Последняя загруженная таблица курсов сохраняется, поэтому конвертер отвечает и без связи
• Свой короткий список валют вместо всех валют, какие есть

ОДНО ПРИЛОЖЕНИЕ, НЕСКОЛЬКО ИНСТРУМЕНТОВ

Unitool — это хост. На главном экране лежит то, что вы туда положили: «+» открывает полный
список, касание добавляет, долгое нажатие убирает. Само там ничего не появляется.

НАСТРОЙКИ

• Язык — русский или английский, переключается сразу, без перезапуска
• Вибрация — короткий отклик под клавишей, включить или выключить
• Валюты, которые конвертер предлагает первыми
• Номер сборки — на случай, если о чём-то нужно сообщить

КОНФИДЕНЦИАЛЬНОСТЬ

Ничто из введённого вами не уходит с телефона. Вычисления идут на устройстве, и ни результат
расчёта, ни то, что вы ввели в конвертер, никуда не передаётся. Нет аналитики, нет сбора сбоев,
нет рекламного идентификатора, нет аккаунта.

Сеть приложение всё же использует — ровно для двух вещей. Конвертер скачивает опубликованные
курсы: целиком таблицу, не сообщая, какая валюта вас интересует. А уведомления доставляет Firebase
Cloud Messaging, который выдаёт этой установке приложения идентификатор, чтобы сообщение нашло
адресата; после переустановки или очистки данных идентификатор становится новым.

На Android 13 и новее приложение спрашивает, нужны ли вам уведомления вообще. Откажитесь — всё
остальное работает ровно так же.

Разрешения: интернет, вибрация (отключается в настройках), уведомления на Android 13 и новее
(от них можно отказаться), камера — только когда вы сами сканируете QR-код в приложении 2FA, — и
биометрия, чтобы приложение 2FA открывалось по отпечатку или лицу. Проверяет Android; приложение
узнаёт только «да» или «нет».

БЕЗ РЕКЛАМЫ. БЕЗ ПОКУПОК. БЕЗ ПОДПИСКИ. БЕЗ ВХОДА.
```
